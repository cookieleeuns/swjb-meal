# SwjbMeal
바탕화면에서 수원정보과학고등학교의 일일 급식을 간편하게 확인할 수 있는 메모형 위젯입니다.
[학교 공식 홈페이지](https://swjb-h.goesw.kr/swjb-h/ad/fm/foodmenu/selectFoodMenuView.do)에서 주간 급식표 데이터를 크롤링해 바탕화면 위젯에 표시합니다.

![스크린샷](https://i.imgur.com/jE8AORh.png)

## 소개
급식이 맛있는 우리 학교, 일일 식단을 번거롭게 홈페이지 접속이나 출력물을 볼 필요 없이 사용자가 컴퓨터에서 간편하게  확인할 수 있도록 바탕화면 위젯 형태로 제작했습니다.

## 기능
- 일일 식단 조회 (◀ ▶ 버튼으로 날짜 이동)
- 열량 정보 확인
- 알레르기 정보 및 경고 제공
- 위젯형 애플리케이션 제공
- 3일마다 자동으로 조회

## 구현
초기 프로토타입은 Python으로 제작되었으나, 3가지 문제가 확인되어 Claude AI의 도움을 받아 **C++로 포팅**했습니다.
1. 위젯 형태의 구현이 힘들다 (제약 존재)
2. 실행 속도가 느리다
3. 메모리를 많이 점유하고 무겁다

현재 프로젝트는 **반정형 데이터**인 HTML 홈페이지에서 **크롤링**해오는 방식이기 때문에 몇 가지 한계점 (제한, 데이터 부족 등)이 존재합니다.
